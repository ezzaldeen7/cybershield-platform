# الجزء العملي — منصة درع الوعي السيبراني

هذا المجلد يحتوي على النموذج الأولي العملي لمنصة عربية تفاعلية للتوعية بالجرائم الإلكترونية.

## الوظائف المنفذة

- لوحة نظرة عامة للمنصة.
- محلل آمن للروابط يعتمد على قراءة البنية النصية دون فتح الرابط أو الاتصال بوجهته.
- محلل تعليمي للرسائل يبحث عن مؤشرات الاستعجال وطلب البيانات الحساسة والروابط والمرفقات.
- مسار دروس توعوية.
- اختبار تفاعلي مع تصحيح وتغذية راجعة.
- واجهة عربية متجاوبة مع الهواتف.
- تسجيل الدخول عبر Manus OAuth المتاح في قالب المشروع.

## التشغيل محليًا

يتطلب المشروع Node.js و pnpm.

```bash
pnpm install
pnpm dev
```

بعد التشغيل، افتح الرابط المحلي الذي يظهر في الطرفية.

## فحوصات المشروع

```bash
pnpm check
pnpm test
pnpm build
```

## ملاحظة أمنية

المحلل الموجود في هذه النسخة تعليمي فقط. لا يُدخل المستخدم كلمات مرور حقيقية أو بيانات مالية أو روابط لا يملك تصريحًا بفحصها. لا يقوم النظام بفتح الروابط أو إرسال الرسائل إلى خدمات خارجية.

## بنية مهمة

- `client/src/pages/Home.tsx`: واجهة المنصة والوظائف التفاعلية.
- `client/src/App.tsx`: مسارات التطبيق.
- `client/src/index.css`: الهوية البصرية والتنسيقات.
- `client/index.html`: إعدادات اللغة والعنوان.
- `server/`: خدمات القالب والمصادقة.
- `drizzle/`: مخطط قاعدة البيانات الجاهز للتوسعة.
