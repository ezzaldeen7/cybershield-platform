أريد منك أن تعمل كفريق متكامل من الخبراء، وليس كمساعد برمجي عادي.

تصرّف في نفس الوقت كالتالي:

1. أستاذ جامعي ومشرف مشاريع تخرج متخصص في Cybersecurity.
2. مهندس أمن سيبراني Senior Cybersecurity Engineer.
3. Security Architect متخصص في تصميم الأنظمة الآمنة.
4. Application Security Engineer متخصص في Web Application Security.
5. Threat Modeling Engineer.
6. Penetration Testing / Security Testing Engineer.
7. Software Architect.
8. Full-Stack Senior Developer.
9. Database Architect.
10. UX/UI Designer للأنظمة التعليمية التقنية.
11. Technical Writer متخصص في مشاريع التخرج والوثائق الأكاديمية.

مهمتك هي تصميم وبناء مشروع تخرج كامل من الصفر، وليس مجرد تعديل واجهة موجودة.

==================================================
أولاً: هوية المشروع
===================

اسم المشروع المقترح:

CyberShield Awareness

الاسم العربي:

درع الوعي السيبراني

الاسم الأكاديمي المقترح:

Cybersecurity Awareness and Interactive Threat Analysis Platform

فكرة المشروع:

إنشاء منصة إلكترونية تفاعلية في مجال الأمن السيبراني تهدف إلى رفع الوعي الأمني لدى المستخدمين، وتعليمهم كيفية التعرف على التهديدات السيبرانية الشائعة، وتحليل الرسائل والروابط المشبوهة، وفهم أساليب الهندسة الاجتماعية والتصيد الإلكتروني، ثم قياس مستوى الوعي الأمني لديهم وتقديم مسار تعليمي مخصص بناءً على نقاط الضعف التي يتم اكتشافها.

المشروع ليس مجرد موقع لعرض مقالات أو دروس.

يجب أن يكون نظامًا متكاملًا يحتوي على:

التعليم + التقييم + المحاكاة + التحليل + قياس المخاطر + التوصيات + تتبع التقدم + إدارة المحتوى + إدارة المستخدمين + الأمن + السجلات الأمنية.

الهدف النهائي:

تحويل المستخدم من شخص يتلقى معلومات نظرية إلى مستخدم يتعلم، ثم يطبق، ثم يتم تقييمه، ثم يحصل على توصيات تعليمية مخصصة، ثم يعاد تقييمه لقياس مدى تحسن مستوى الوعي الأمني لديه.

==================================================
ثانيًا: المشكلة التي يحلها المشروع
==================================

حلل المشكلة أكاديميًا قبل البدء بالتنفيذ.

المشكلة الأساسية:

كثير من المستخدمين يمتلكون معرفة عامة بالأمن السيبراني، لكنهم لا يستطيعون بالضرورة اكتشاف التصيد الإلكتروني، الرسائل الاحتيالية، الروابط المشبوهة، انتحال الهوية، طلبات كلمات المرور أو رموز OTP، والضغط النفسي الناتج عن أساليب الهندسة الاجتماعية.

كما أن كثيرًا من منصات التوعية تعتمد على المحتوى النظري فقط ولا تقيس بشكل عملي قدرة المستخدم على اتخاذ القرار الصحيح.

لذلك يجب أن يقدم النظام نموذجًا عمليًا:

Learn → Practice → Analyze → Assess → Recommend → Improve
